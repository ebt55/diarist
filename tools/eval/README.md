# tools/eval

Placeholder for the evaluation harness (Phase 4): a Python project managed with `uv` that scores meet-assist transcripts against hand-labelled references (DER, cpWER, words assigned to the wrong speaker, with AMI ES2002a as the public baseline) and commits the results as a regression table. It is a dev-only tool: it is never bundled with or required by the app. See `docs/plans/05-phase4-eval-harness.md` and `docs/05-eval-data.md`.
